Privacy Policy

Effective date: August 14, 2026

This policy covers the website serendibeats.github.io and serendibeats reference sync, an internal software tool operated by serendibeats ("we", "us").

Who uses the tool

serendibeats reference sync is a private, internal tool used solely by the serendibeats team. It is not distributed to, or usable by, any third party. No accounts other than the operator's own are ever connected.

What data it accesses

With the account owner's authorization, the tool reads — via the official Pinterest API, with read-only scopes — boards and Pins that the authenticated account owner has saved to their own account. It does not access data belonging to any other person, and it cannot post, edit, or delete anything.

How the data is used

Accessed reference material is used only to organize the team's internal creative research within our private team workspace. It is never sold, shared, published, or transferred to third parties, and it is not used for advertising or profiling.

Credentials

API credentials are stored locally on the operator's own machine and are never transmitted to any server we operate or to third parties.

This website

This website is a static page. It sets no cookies and runs no analytics or trackers.
